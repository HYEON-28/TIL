# TIL (Today I Learned)

매일 배운 것을 기록하는 학습 저장소입니다. 백엔드, 프론트엔드, 인프라, 알고리즘 등 소프트웨어 엔지니어로 성장하기 위해 학습한 내용을 주제별로 정리합니다.

## 디렉토리 구성

| 디렉토리         | 내용                                                                             |
| ---------------- | -------------------------------------------------------------------------------- |
| `java/`          | Java 기본 문법, 타입, OOP                                                        |
| `spring/`        | Spring 프레임워크 (어노테이션, AOP, 트랜잭션, Security, 엔티티, 마이그레이션 등) |
| `database/`      | MySQL, JOIN, 스키마와 테이블의 차이                                              |
| `frontend/`      | React (Hooks), TypeScript, 브라우저 동작 원리, 토이 프로젝트                     |
| `infra/`         | AWS (서브넷, 라우팅 테이블, 인터넷 게이트웨이), Docker, AWS SAA 자격증 덤프      |
| `algorithm/`     | Prefix Sum, Binary Search, Greedy, DP, 소수 판별                                 |
| `devops/`        | CI/CD                                                                            |
| `git/`           | Git 설정, commit reset 등 활용법                                                 |
| `system design/` | 대규모 트래픽 처리 아키텍처                                                      |
| `ai/`            | Claude Code 사용 정리                                                            |
| `IDE/`           | IntelliJ 활용 팁                                                                 |
| `report/`        | JXLS 등 리포트 도구                                                              |
| `etc/`           | 트랜잭션 예제, 트리거 버그 등 잡학                                               |
| `diary/`         | 학습 회고와 단상                                                                 |
| `roadmap/`       | 소프트웨어 엔지니어 학습 로드맵                                                  |
