## Producer / Consumer 패턴
API Gateway
   ↓
Lambda (Producer)
   ↓
SQS Queue
   ↓
Lambda (Consumer)
   ↓
Aurora DB

### 장점
- SQS가 데이터를 잠시 저장 -> DB 처리속도와 상관없이 요청 수용 가능
- DB가 처리 가능한 속도로만 작업 수행 (Consumer Lambda의 동시 실행을 n개로 제한하는 등의 방법 사용)
