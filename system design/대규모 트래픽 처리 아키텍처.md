# 대규모 트래픽 처리 아키텍처

## Producer / Consumer 패턴

트래픽이 몰릴 때 DB에 직접 부하를 주지 않기 위해 Queue를 중간에 두는 패턴.

```
API Gateway
↓
Lambda (Producer)
↓
SQS Queue
↓
Lambda (Consumer)
↓
Aurora DB
```

### 장점

- SQS가 데이터를 잠시 저장 -> DB 처리속도와 상관없이 요청 수용 가능
- DB가 처리 가능한 속도로만 작업 수행 (Consumer Lambda의 동시 실행을 n개로 제한하는 등의 방법 사용)

### 단점

- 처리가 즉시 되지 않아 실시간성이 필요한 경우엔 적합하지 않음
- 구조가 복잡해지고 디버깅이 어려워짐
