# Go가 빠른 이유

Go는 Java, Python 등의 다른 언어에 비해 성능이 좋은게 특징이다.
무슨 차이로 성능이 좋은지 알아보았다.

## Java대비 빠른 이유

- Java는 JVM위에서 실행되어 JVM오버헤드가 존재함
- GC설계가 Go가 고성능.
- Go의 스레드가 더 경량이고 성능이 좋다.

## Python대비 빠른 이유

- Python은 인터프리터 언어라 오버헤드(원 작업 외의 부가작업)큼
  - Go는 미리 컴파일
- Python은 런타임에 타입을 결정하여 타입체크비용 발생
  - Go는 컴파일 타임에 확정
- Python은 GIL때문에 멀티스레드에서도 한번에 하나의 스레드만 실행
  - Go는 고루틴(goroutine)으로 병렬실행 가능

\*GIL: 멀티코어 CPU가 일빈적이지 않은 시절 파이썬에서 메모리 안정성을 위해 만들었지만, 멀티스레드 성능이 희생됨
