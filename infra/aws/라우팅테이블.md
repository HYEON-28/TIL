# 라우팅테이블

- "이 목적지로 가려면 어디로 보낼지"를 정의하는 규칙임 (교통정리, 나가는 패킷에 대한 네비게이션)
- 여러 규칙에 해당할 때 더 구체적인(prefix가 긴) 규칙이 우선 적용됨

## public 서브넷

IGW로 나가는 규칙이 설정되어 있으면 public 서브넷

- 10.0.0.0/16 -> local : 10.0.0.0 ~ 10.0.255.255 범위이면 VPC 내부에서 직접 전달
- 0.0.0.0/0 -> IGW : 나머지 모든 목적지는 인터넷 게이트웨이로

## private 서브넷

- 10.0.0.0/16 -> local
