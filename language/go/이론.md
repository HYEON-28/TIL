### naked returns

return할 변수, 값을 명시하지 않고 함수의 정의 부분에 적을 수 있음
-> 코드를 짧게쓰기위해 존재하지만 실무에서는 거의 사용하지 않음.

```
	func lenAndUpper(name string) (int, string) {
		return len(name), strings.ToUpper(name)
	}

  func lenAndUpper2(name string) (length int, uppercase string) { // 여기에서 return함
    length = len(name)
    uppercase = strings.ToUpper(name)
    return
	}
```

### defer

함수의 실행이 끝났을 때(return을 실행한 후) defer문을 실행함

```
  func lenAndUpper2(name string) (length int, uppercase string) {
    defer fmt.Println("I'm done")
    length = len(name)
    uppercase = strings.ToUpper(name)
    return
	}
```

## Pointer

&는 주소를 반환 \*는 주소가 가리키는 값에 접근

```
func main() {
	a := 2
	b := &a
	*b = 10
	fmt.Println(a) // 10
}
```

## Arrays and Slices

