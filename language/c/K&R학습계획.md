# 🚀 임베디드 직무 전환을 위한 K&R C언어 4주 속성 마스터 계획

본 학습 계획은 웹 개발 경험자를 대상으로 하며, K&R(The C Programming Language) 교재에서 **임베디드 핵심(메모리 제어, 하드웨어 접근)**에만 집중하여 최단기에 뼈대를 세우도록 구성되었습니다.

---

## 📅 주차별 학습 계획

### 🗓️ 1주차: 포인터의 기본과 배열 (교재 5장 전반부)

> **목표:** 웹의 추상화된 메모리를 벗어나, 실제 하드웨어 주소(Address)의 개념을 확립합니다.

- **핵심 학습 내용**
  - `&`(주소 연산자)와 `*`(역참조 연산자)의 완벽한 구분
  - 포인터 연산(`p++`, `p += i`)이 자료형 크기(`sizeof`)에 따라 실제 주소를 몇 바이트씩 이동시키는지 이해
  - "배열의 이름은 사실 첫 번째 요소의 주소값(`&array[0]`)이다"라는 규칙 마스터
- **임베디드 관점 핵심:** 하드웨어 센서의 레지스터 주소에 직접 접근하여 데이터를 읽고 쓰는 모든 과정의 기초가 됩니다.
- **실습 가이드:** 연습장에 메모리 격자를 그리고 주소값(예: `0x1000`)을 직접 적어가며 화살표로 포인터 가리키기 연습하기.

---

### 🗓️ 2주차: 포인터 배열과 다차원 포인터 (교재 5장 후반부)

> **목표:** 복잡하게 얽힌 주소 체계를 이해하고 함수 포인터를 맛봅니다.

- **핵심 학습 내용**
  - 포인터 배열(`char *lineptr[]`)과 일반 2차원 배열의 메모리 구조 차이점 분석
  - **함수 포인터(Function Pointer)**의 개념 이해 (함수의 시작 주소 바인딩)
  - `void *` 포인터의 의미와 타입 캐스팅(Type Casting)의 필요성
- **임베디드 관점 핵심:** 버튼 인터럽트가 발생했을 때 실행할 콜백 함수들을 배열로 관리하는 **'인터럽트 벡터 테이블(Interrupt Vector Table)'**이나 **'이벤트 핸들러'** 구조의 핵심 뼈대가 됩니다.

---
