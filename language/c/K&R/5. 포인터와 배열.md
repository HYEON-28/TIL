# Chapter5. 포인터와 배열

## 5.1 포인터와 주소

> 포인터: 다른변수의 주소를 그 값으로 가지는 변수

- 포인터는 배열과 밀접한 관계를 가짐.

> &: 번지를 알아내는 연산자
> p=&c

&: 일반변수에 쓰는 것
\*: 포인터 변수에 쓰는것 그 주소로 찾아가게 함

`int *ip;` : 정수형 변수의 포인터 선언
`ip = &x` : \*ip는 x대신 사용가능함.

## 5.2 포인터와 함수의 매개변수

- 포인터를 이용하면 함수안에서 변수에 직접 접근 가능함.

```
swap(&a, &b);

void swap(int *px, int *py)
{
  int temp;

  temp = *px;
  *px = *py;
  *py = temp;
}
```
