# 메모리 구조

C언어 프로그램이 실행될 때 가상메모리 공간은 역할에 따라 5개 영역으로 나뉨.

| 메모리 영역     | 저장되는 데이터 종류                                                          | 특징 / 수정 가능 여부                           | 하드웨어 매핑 (임베디드)     |
| :-------------- | :---------------------------------------------------------------------------- | :---------------------------------------------- | :--------------------------- |
| **Code (Text)** | 실제 실행할 **기계어 코드 명령문**                                            | 읽기 전용 (**Read-Only**)                       | **ROM (Flash)**              |
| **Data (G/S)**  | **초기화 값이 있는** 전역 변수, static 변수<br>_(예: `int a = 10;`)_          | 읽기/쓰기 가능 (**Read/Write**)                 | **RAM**<br>(원본은 ROM 보관) |
| **BSS**         | **초기화 값이 없는(0인)** 전역 변수, static 변수<br>_(예: `int b;`)_          | 프로그램 시작 시 **전부 0으로 자동 초기화**됨   | **RAM**                      |
| **Heap**        | 개발자가 필요할 때 빌려 쓰는 동적 메모리<br>_(예: `malloc()`, `calloc()`)_    | 런타임에 크기 결정, **반드시 수동 해제** 필요   | **RAM**                      |
| **Stack**       | 함수의 **지역 변수, 매개변수**, 리턴 주소<br>_(예: 함수 내 `int amessage[]`)_ | 함수가 켜지면 생성, 끝나면 **자동 소멸** (LIFO) | **RAM**                      |

### 💡 질문자님이 통달하신 개념과 연결 짓기

1.  **`char *pmessage = "hello";` 에서 `"hello"`가 저장되는 곳:** `Code(Text)` 영역 뒤편의 읽기 전용 상수 구역(`ROData`)입니다. 임베디드에서는 **ROM**에 머무르기 때문에, 이 주소를 가리키는 포인터 방식을 쓰면 귀한 **RAM**을 아낄 수 있다고 했던 것입니다.
2.  **`char amessage[] = "hello";` 가 저장되는 곳:** 함수 내부라면 **Stack** 영역입니다. 실행 시점에 ROM에 있던 `"hello"`를 스택 RAM 상자로 복사해 오기 때문에 RAM 용량을 쓰게 되고, 대신 RAM이므로 값 수정이 가능해집니다.
3.  **`Data`와 `BSS`를 왜 굳이 나눌까요?**
    - 초기화 값이 있는 `Data` 변수들은 그 초기값(예: 10, 20)을 실행 파일이 품고 있어야 하므로 **ROM 용량을 차지**합니다.
    - 반면 초기값이 없는 `BSS` 변수들은 "이 변수들은 0으로 채울 거다"라는 개수 정보만 갖고 있다가 램이 켜질 때 부팅 코드(Startup code)가 **RAM에 한 번에 0을 쫙 깔아주기 때문에 ROM 용량을 거의 차지하지 않습니다.** 영리한 하드웨어 다이어트 기법이죠.
