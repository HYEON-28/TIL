## 1.1 시작

```
  gcc hello.c -o hello
```

실행방법

```
  ./hello.exe
```

## 1.2 변수와 수식 표현

- C에서 정수끼리 계산의 결과는 정수형이 됨

```
  printf("%3d\t%6d\n", fahr, celsius);
```

- %d: 10진 정수
- %o: 8진 정수
- %x: 16진 정수
- %c: 문자
- %s: 문자열
