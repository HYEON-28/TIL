# 구조체

서로 다른 타입의 데이터들을 하나로 묶어서 관리할 수 있는것

> 배열: 서로 같은 타입의 데이터

## 구조체 포인터와 화살표(->) 연산자

```
typedef struct {
  int id;
  char name[20];
  double grade;
} Student;

Student s = {10, "Lee", 3.8};
Student *ptr = &s;

(*ptr).id = 20;
ptr->id = 20;
```

- 구조체 멤버는 메모리에 `선언 순서대로 연속 배열` 된다.

## 구조체 패딩

- 구조체 멤버의 크기를 모두 더하면 전체 구조체의 크기가 되지 않음
- 컴파일러가 멤버변수 사이에 임의의 빈 공간을 끼워넣음. -> 구조체 패딩
