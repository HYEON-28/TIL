# Java의 특징
- 운영체제에 독립적임(JVM 사용)
  - JVM은 운영체제에 종속적이다
  - 즉, JVM만 설치되어 있으면 어떤 OS에서든 같은 `.class` 파일을 실행할 수 있다
- 자동 메모리 관리
  - GC(Garbage Collector)가 사용하지 않는 객체를 알아서 메모리에서 제거해줌
  - C/C++처럼 직접 메모리 해제를 안해도 된다
- 멀티쓰레드 지원
  - 언어 차원에서 멀티쓰레드를 지원함 (`Thread`, `Runnable` 등)
- 동적로딩 지원
  - 필요 시점에 클래스 로딩하여 사용함
  - 애플리케이션 실행 시 모든 클래스를 올리지 않아도 된다
