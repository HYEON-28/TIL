# macOS용 VS Code 유용한 단축키 정리

## 1. 파일/탐색 관련

| 기능             | 단축키                      |
| ---------------- | --------------------------- |
| 파일 빠르게 열기 | `⌘ + P`                     |
| 최근 파일 검색   | `⌘ + P` 후 파일명 일부 입력 |
| 전체 명령 팔레트 | `⌘ + Shift + P`             |
| 새 파일          | `⌘ + N`                     |
| VSCode 전체 종료 | `⌘ + Q`                     |

---

## 2. 코드 이동

| 기능                 | 단축키          |
| -------------------- | --------------- |
| 정의로 이동          | `F12`           |
| 정의 미리보기        | `⌥ + F12`       |
| 이전 위치로 돌아가기 | `⌃ -`           |
| 심볼 검색            | `⌘ + Shift + O` |
| 파일 내 검색         | `⌘ + F`         |
| 프로젝트 전체 검색   | `⌘ + Shift + F` |
| 줄 이동              | `⌃ + G`         |

---

## 3. 편집 생산성

| 기능                | 단축키          |
| ------------------- | --------------- |
| 현재 줄 복사        | `Shift + ⌥ + ↓` |
| 현재 줄 이동        | `⌥ + ↑/↓`       |
| 줄 삭제             | `⌘ + Shift + K` |
| 여러 줄 선택        | `⌥ + 클릭`      |
| 같은 단어 동시 선택 | `⌘ + D`         |
| 같은 단어 전체 선택 | `⌘ + Shift + L` |
| 한 줄 주석          | `⌘ + /`         |
| 자동 정렬           | `Shift + ⌥ + F` |

---

## 4. 멀티 커서

| 기능              | 단축키        |
| ----------------- | ------------- |
| 위/아래 커서 추가 | `⌥ + ⌘ + ↑/↓` |
| 마우스로 멀티커서 | `⌥ + 클릭`    |

예시:

```js
const a = 1;
const b = 2;
const c = 3;
```

---

## 5. 터미널 관련

| 기능        | 단축키                |
| ----------- | --------------------- |
| 터미널 열기 | `⌃ + \``              |
| 새 터미널   | `⌘ + Shift + 5`       |
| 터미널 이동 | `⌘ + Shift + [` / `]` |

---

## 6. 리팩토링/개발 필수

| 기능        | 단축키      |
| ----------- | ----------- |
| Rename      | `F2`        |
| Quick Fix   | `⌘ + .`     |
| 자동 import | `⌘ + .`     |
| 코드 접기   | `⌥ + ⌘ + [` |
| 코드 펼치기 | `⌥ + ⌘ + ]` |

---

## 7. Git 관련

| 기능                | 단축키          |
| ------------------- | --------------- |
| Source Control 열기 | `⌃ + Shift + G` |
| 변경 파일 이동      | `↑/↓`           |
| diff 보기           | `Enter`         |
