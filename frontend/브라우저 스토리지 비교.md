# 브라우저 스토리지 비교

## localStorage vs sessionStorage

| 구분      | localStorage                   | sessionStorage                |
| --------- | ------------------------------ | ----------------------------- |
| 유지 기간 | 직접 삭제 전까지 영구 보존     | 탭(세션) 종료 시 자동 삭제    |
| 탭 공유   | 같은 도메인의 모든 탭에서 공유 | 해당 탭에서만 유효            |
| 용량      | 약 5~10MB                      | 약 5~10MB                     |
| 접근 범위 | 동일 출처(origin)              | 동일 출처 + 동일 탭           |
| 서버 전송 | 전송 안 됨                     | 전송 안 됨                    |
| 주요 용도 | 로그인 토큰, 사용자 설정       | 임시 폼 데이터, 일회성 플래그 |

## 여러 Storage 비교

| Storage          | 유지 기간             | 용량      | 특징                                           |
| ---------------- | --------------------- | --------- | ---------------------------------------------- |
| `localStorage`   | 영구                  | ~5MB      | 도메인 내 모든 탭 공유                         |
| `sessionStorage` | 탭 종료 시 삭제       | ~5MB      | 해당 탭에서만 유효                             |
| `Cookie`         | 설정한 만료일까지     | ~4KB      | 서버로 자동 전송됨, `HttpOnly`/`Secure` 옵션   |
| `IndexedDB`      | 영구                  | 수백MB~GB | 비동기 API, 구조화된 대용량 데이터 저장        |
| `Cache API`      | 명시적 삭제 전까지    | 수백MB~GB | Service Worker와 함께 사용, 네트워크 응답 캐싱 |
| `sessionCookie`  | 브라우저 종료 시 삭제 | ~4KB      | 만료일 미설정 쿠키, 브라우저 닫으면 삭제       |
