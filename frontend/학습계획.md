# React + TypeScript 단계별 학습계획

---

## 1단계 · 입문

> React와 TypeScript를 처음 접하는 단계입니다. 기본 문법과 환경 설정, 핵심 개념의 이해에 집중합니다.

### TypeScript 기초

- **기본 타입 선언** — `string`, `number`, `boolean`, `null`, `undefined`, `any`, `unknown`
- **배열 및 튜플 타입** — `string[]`, `[string, number]` 등 선언 방법
- **객체 타입 & type alias** — `type` 키워드로 객체 형태 정의하기
- **함수 타입 선언** — 매개변수 타입, 반환 타입 명시
- **타입 추론 (Type Inference)** — TypeScript가 자동으로 타입을 추론하는 원리

### React 기초

- **CRA / Vite + TypeScript 프로젝트 생성** — 개발 환경 세팅 및 tsconfig 기본 이해
- **함수형 컴포넌트 기본 구조** — `React.FC`, JSX 반환, 컴포넌트 파일 구조
- **Props 전달 및 타입 정의** — `interface` / `type`으로 Props 타입 선언하기
- **useState 기본 사용** — `useState<T>`로 상태 타입 명시
- **이벤트 핸들링 기초** — `onClick`, `onChange` 이벤트 타입 처리
- **조건부 렌더링** — `&&` 연산자, 삼항 연산자로 UI 분기
- **리스트 렌더링 & key prop** — `map()`을 활용한 배열 렌더링

> 💡 이 단계는 '동작하는 코드'를 만드는 것에 집중합니다. 타입 오류를 무서워하지 말고 TypeScript가 알려주는 메시지를 읽는 연습을 하세요.

---

## 2단계 · 초급

> 기본 문법을 넘어 컴포넌트 설계와 타입 시스템 활용 방법을 이해합니다. 실용적인 패턴을 익히는 단계입니다.

### TypeScript 심화 기초

- **interface vs type alias 차이** — 확장(`extends`) 방식, 선언 병합 차이점
- **유니온 타입 & 인터섹션 타입** — `string | number`, `A & B` 패턴
- **옵셔널 프로퍼티 & Non-null assertion** — `?`, `!`, `?.` 연산자 활용
- **Enum vs Const Assertion** — `enum`과 `as const`의 차이와 사용 시점
- **타입 단언 (as)** — 타입 캐스팅의 원리와 남용 위험성

### React 컴포넌트 패턴

- **useEffect 기본 & 의존성 배열** — 사이드 이펙트 처리, cleanup 함수
- **컴포넌트 분리 설계** — 재사용 가능한 컴포넌트 props 인터페이스 설계
- **children prop 타입 정의** — `React.ReactNode`, `React.PropsWithChildren`
- **이벤트 타입 정확히 쓰기** — `React.ChangeEvent<HTMLInputElement>`, `MouseEvent` 등
- **폼(Form) 컴포넌트 구현** — controlled input, 폼 상태 관리
- **커스텀 훅 기초** — 로직 분리를 위한 `useXxx` 패턴 만들기

> 💡 이 단계에서는 'props 타입을 얼마나 정확하게 정의하느냐'가 핵심입니다. `any` 사용 없이 타입을 잡는 연습을 집중적으로 하세요.

## 3단계 · 중급

> 실무에서 자주 마주치는 패턴을 다룹니다. 제네릭, 고급 훅, 전역 상태 관리, 비동기 처리를 TypeScript와 함께 다룹니다.

### TypeScript 제네릭

- **제네릭 함수 & 제네릭 인터페이스** — `function identity<T>(arg: T): T` 패턴
- **제네릭 제약 조건 (extends)** — `<T extends object>`, `<T extends keyof U>`
- **유틸리티 타입 활용** — `Partial`, `Required`, `Readonly`, `Pick`, `Omit`, `Record`
- **조건부 타입 기초** — `T extends U ? X : Y` 패턴
- **함수 오버로딩** — 동일 함수명으로 다양한 시그니처 정의

### React 고급 패턴

- **useReducer + TypeScript** — Action 유니온 타입, Reducer 함수 타입 정의
- **Context API + TypeScript** — `createContext` 타입 정의, Provider 패턴
- **useRef 타입 지정** — `RefObject` vs `MutableRefObject`, DOM 참조
- **커스텀 훅 고급 패턴** — 제네릭 커스텀 훅, 반환 타입 명시
- **비동기 데이터 패칭 타입 처리** — `loading` / `error` / `data` 상태 타입 설계
- **React.memo & useMemo / useCallback** — 불필요한 리렌더링 방지, 타입 유지
- **Compound Component 패턴** — 컴포넌트 합성으로 유연한 API 설계

> 💡 제네릭을 이해하면 TypeScript의 진짜 힘이 나옵니다. `any` 대신 제네릭으로 해결하는 습관을 들이세요.

## 4단계 · 고급

> 실무 프로젝트 수준의 아키텍처와 고급 타입 시스템을 다룹니다. 코드 품질과 유지보수성을 높이는 패턴에 집중합니다.

### 고급 TypeScript

- **Template Literal Types** — `'get' | 'post'` → `` `/${string}` `` 등 동적 타입
- **Mapped Types** — `{ [K in keyof T]: ... }` 패턴으로 타입 변환
- **infer 키워드** — 조건부 타입 안에서 타입 추출하기
- **Discriminated Union (태그 유니온)** — `type` 필드로 분기하는 타입 안전 패턴
- **Declaration Merging & Module Augmentation** — 라이브러리 타입 확장하기
- **ReturnType, Parameters, Awaited 유틸리티** — 함수 / 비동기 타입 추출 유틸리티

### React 아키텍처 & 상태관리

- **전역 상태 관리 (Zustand / Jotai + TS)** — 스토어 타입 정의, 셀렉터 패턴
- **React Query (TanStack Query) + TypeScript** — 쿼리 키 타입, `useQuery` 제네릭 활용
- **고차 컴포넌트(HOC) 타입 정의** — `withXxx` 패턴의 Props 타입 래핑
- **Render Props 패턴 타입 처리** — children as function 패턴
- **에러 바운더리 구현** — 클래스 컴포넌트 + ErrorBoundary 타입
- **폼 라이브러리 통합 (React Hook Form + Zod)** — 스키마 기반 타입 추론, 유효성 검사

> 💡 이 단계부터는 '내가 만든 타입이 다른 개발자에게 어떻게 보일까'를 생각하세요. 타입 자체가 문서 역할을 합니다.

## 5단계 · 심화·실무

> 라이브러리 수준의 타입 설계, 퍼포먼스 최적화, 테스트, 모노레포 등 대규모 프로젝트를 다룰 수 있는 실무 최고급 수준입니다.

### TypeScript 전문가 수준

- **엄격 모드(strict) 전체 이해** — `strictNullChecks`, `noImplicitAny` 등 모든 옵션
- **Declaration File (.d.ts) 작성** — JS 라이브러리에 타입 정의 파일 직접 추가
- **Variance (공변 / 반변 / 불변)** — 제네릭 타입의 서브타입 관계 이해
- **브랜드 타입 (Branded Types)** — `UserId` vs `OrderId` 구분하는 nominal typing
- **타입 레벨 프로그래밍** — 재귀 타입, 타입으로 연산하기, `DeepPartial` 구현
- **tsconfig paths & 모노레포 타입 공유** — 패키지 간 타입 참조 설계

### React 실무 & 최적화

- **React Server Components 개념 및 타입** — Next.js 14+ App Router, async 컴포넌트 타입
- **코드 스플리팅 & 지연 로딩 타입 처리** — `React.lazy`, `Suspense`, `dynamic import` 타입
- **Web Worker / Worker Thread 통합** — 메시지 타입 정의, 양방향 통신 타입 설계
- **테스트 코드 작성 (Testing Library + Vitest)** — 컴포넌트 테스트, 모킹 타입, 커버리지
- **성능 분석 & 최적화 전략** — React DevTools Profiler, 렌더링 병목 분석
- **접근성(a11y) + TypeScript** — ARIA 속성 타입, 키보드 네비게이션 타입 처리
- **라이브러리 설계 & 배포** — npm 패키지 타입 번들링, rollup + dts 설정

> 💡 5단계는 '팀을 위한 타입'을 설계하는 단계입니다. 내 코드를 사용하는 사람이 타입 오류 없이 쓸 수 있도록 API를 설계하는 것이 목표입니다.
