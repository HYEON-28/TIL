## 리액트 프로젝트 만들기

### npm과 npx

npm(node package manager): Node.js 프로젝트에서 개발에 유익한 오픈소스 라이브러리를 쉽게 설치할수 있게 함
그 중 CRA와 같은 독립실행 프로그램 -> ₩npm i -g₩ 형태로 설치해야 하지만 최신버전 유지하기 힘듦

npx: 패키지들의 가장 최근 버전을 찾아서 npm i -g 명령으로 설치해 줌

CRA와 같은 글로벌로 설치해야 하는 프로그램이 있고 최신버전을 유지하기 힘든 문제가 있다.
npx를 쓰면 최신버전을 찾아서 글로벌로 설치해 준다.

### 타입스크립트 프로젝트 생성

> npx create-react-app 프로젝트\_이름 --template typescript

### 웹팩이란?

다양한 프론트엔드쪽 파일을 단순한 형태로 변환

- 빌드모드: npm run build

npm install -g serve
serve -s build : 실행해라

npm start: 웹팩이 서버로 동작한다.
