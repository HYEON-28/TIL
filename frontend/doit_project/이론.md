## 02. 리액트 동작원리

### 02-1. 가상 DOM 이해하기

리액트 프레임워크의 기본 3요소

- 가상 DOM, JSX 구문, 컴포넌트

#### react와 react-dom 패키지

- react: 컴포넌트, jsx, 리액트 훅 등 랜더러에 무관한 기능
- 중간에 가상 DOM 이라는 메커니즘 존재함
- react-dom/client : CSR방식 웹 앱 기능 제공
- react-dom/server : SSR방식 웹 앱 기능 제공
- react-native : 모바일앱에 특화된 렌더링 기능

> CSR방식 웹앱과 SSR방식 웹앱의 차이: CSR은 브라우저에서 렌더링, SSR은 서버에서 렌더링 함
> 과거: SPA 붐 → CSR 위주 (React 단독)
> 현재: 성능 + SEO 요구 증가 -> SSR 사용 증가
> SPA(CSR)는 SEO에 상대적으로 불리하고, 이를 보완하기 위해 SSR을 사용한다.

#### DOM

- document 객체: window.document 혹은 document -> html요소

root.render(pVirtualDOM) : 가상DOM을 물리DOM으로 전환해줌

- 리액트는 React.createElement 함수로 다양한 HTML요소를 가상 DOM트리 구조로 구현한 뒤, render 메서드가 호출되는 순간 가상DOM 트리를 물리 DOM트리로 변환함
- 임의의 물리 DOM 트리에서 일부 HTML 요소의 속성값이 변경될 때 이를 탐지하여 DOM 트리에 반영할 수 있는가?
  - 물리DOM에서는 id값을 가지고 바꾸면 된다. 하지만 가상DOM에서는 id값을 부여하는것 조차 문제다.

### 02-2 JSX 구문 이해하기

<ul>
  <li>
    <a href="http..">
      <p>go to google</p>
    </a>
  </li>
</ul>
이걸 React.createElement
호출로 구현 시..
const CE = React.createElement

const rootVirtualDOM = CE('ul', null, [
CE('li', null, [
CE('a', {href: 'http:.."}, [
CE('p', null, 'go to google')
])
])
])
-> 복잡하다.

따라서 언어확장 형태로 JSX 기능을 추가하였다.
const rootVirtualDOM = (

<ul>
    <li>
      <a href="http..">
        <p>go to google</p>
      </a>
    </li>
  </ul>
)

### 02-3 컴포넌트 이해하기

1. 클래스 컴포넌트
2. 함수 컴포넌트 -> 권장

리액트 컴포넌트: 리액트 기본제공. 첫글자 소문자
사용자 컴포넌트: 직접 구현. 첫글자 대문자의 카멜 표기법

const h1 = <h1>Hello world!</h1>
-> h1은 HTML태그가 아닌 h1컴포넌트임

클래스 컴포넌트

- Component 클래스 상속해야 하고 render()메서드 구현해야 함

js코드와 jsx구문을 함께 쓸 수 있음.

컴포넌트 속성: 컴포넌트에 값을 전달하는 기능

- 부모 컴포넌트가 자식 컴포넌트에 정보를 전달하는 목적으로 사용됨
- 속성값이 변하면 해당 컴포넌트를 다시 렌더링하여 수정된 속성값을 반영해줌.
  <Person name='Jack' age={22} /> -> string이 아닌 경우 {}로 감싸야 함
  <Person person = {{name: 'Jack', age: 32}} />
  -> object는 string이 아니므로 {}로 감쌌음.

클래스형 컴포넌트

```
import {Component} from 'react'

export default class App extends Component {
render() {
return <h1>class component</h1>
}
}
```

함수형 컴포넌트

```
export default function App() {
return <h1>function component</h1>
}
```

함수형 컴포넌트는 import, extends, render등의 상용구가 없어서 간결하게 사용가능함.

### 02-4 key와 children 속성 이해하기

모든 리액트 컴포넌트는 key, children, ref속성을 이미 가짐.

> key: 같은 이름의 컴포넌트가 여러 개일 때 이들을 구분하기 위한 속성
> children: 자식 속성

JSX {...props} 구문

- props에 담긴 다양한 속성을 마치 타입스크립트의 전개 연산자처럼 <p>에 한꺼번에 전달함

<p {...props} />

PropsWithChildren 타입

- Props타입에 반복해서 children 속성을 추가할 필요가 없다
