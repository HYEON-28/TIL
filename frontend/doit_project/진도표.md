# Do it! 리액트로 웹앱 만들기 with 타입스크립트

- 1차시: 리액트 개발 준비 > 리액트 설치와 기타 개발 도구 준비
- 2차시: 리액트 동작 원리 > 가상 DOM과 JSX구문
- 3차시: 리액트 동작 원리 > 컴포넌트와 이벤트 속성
- 4차시: 컴포넌트 CSS 스타일링 > CSS 스타일링
- 5차시: 컴포넌트 CSS 스타일링 > 테일윈드 CSS 스타일링
- 6차시: 컴포넌트 CSS 스타일링 > 플렉스 레이아웃과 daisyui 프레임워크
- 7차시: 함수 컴포넌트와 리액트 훅 > useMemo, useCallback 훅
- 8차시: 함수 컴포넌트와 리액트 훅 > useState, useEffect, useLayoutEffect 훅
- 9차시: 함수 컴포넌트와 리액트 훅 > useRef, useImperativeHandle, useContext 훅
- 10차시: 상태 관리와 리덕스 패키지 > 리덕스 기본 개념과 리듀서 활용
- 11차시: 상태 관리와 리덕스 패키지 > 리덕스 미들웨어
- 12차시: 상태 관리와 리덕스 패키지 > 트렐로 따라 만들기
- 13차시: 리액트 라우터 > 리우터 기본 개념, Outlet 컴포넌트와 중첩 라우팅, 공개/비공개 라우팅
- 14차시: 몽고DB와 API 서버 > 몽고DB 사용
- 15차시: 몽고DB와 API 서버 > REST API 서버와 회원 인증
