# TypeScript를 사용하는 이유

## 런타임 오류를 개발 단계에서 잡는다

JS는 실행해 봐야 타입 오류를 알 수 있지만, TS는 컴파일 시점에 잡아준다.
배포 전에 버그를 제거할 수 있어 디버깅 비용이 줄어든다.

```ts
function add(a: number, b: number) {
  return a + b;
}

add(1, "2"); // 컴파일 에러: '"2"' 형식의 인수는 'number' 형식의 매개변수에 할당될 수 없습니다.
```

## 코드 가독성과 유지보수성 향상

함수 시그니처와 객체 구조가 타입으로 명시되어 있어, 주석이나 문서 없이도 무엇을 받고 무엇을 반환하는지 알 수 있다.
IDE의 자동완성과 리팩토링 기능도 강력해진다.

## 대규모 프로젝트에서 안정성 향상

여러 명이 협업하거나 코드베이스가 커질수록 효과가 크다.
타입을 바꾸면 영향을 받는 모든 곳에 에러가 표시되므로, 변경의 파급 범위를 빠르게 파악할 수 있다.
