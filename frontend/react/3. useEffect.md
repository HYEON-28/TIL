# useEffect
useState / useReducer → 상태를 바꾸는 역할
useEffect → 상태가 바뀐 "이후" 무엇을 할지 결정

다음은 전부 useEffect 영역이다:
- API 호출
- 이벤트 리스너 등록/해제
- 타이머(setTimeout, setInterval)
- DOM 직접 제어
- 외부 라이브러리 연동
- 데이터 동기화

## 의존성 배열 (Dependency Array)
useEffect(() => {
      // 실행할 코드
  }, [count]);  // ← 이 부분
  두 번째 인자는 "이 값들이 변경될 때 effect를 재실행해라" 라는 의미입니다.
- count가 바뀔 때만 실행
- 빈 배열 [] → 마운트 시 1회 실행
- 배열 생략 → 렌더링마다 실행 (거의 안 씀)

## 왜 빈 배열이 "1회"인가?
React는 렌더링마다 이전 의존성 배열 vs 현재 의존성 배열을 비교합니다.
빈 배열 []은 비교할 값이 없음
→ 변경된 값이 절대 없음
→ "재실행 조건"이 절대 충족되지 않음
→ 최초 마운트 때 딱 1번만 실행되고 끝

## 마운트(mount)란?
컴포넌트가 화면에 처음 나타나는 순간
→ 이때 딱 1번 실행
→ 이후 state가 바뀌어 재렌더링이 일어나도 실행 안 됨
→ 화면에서 사라질 때(언마운트)도 실행 안 됨
