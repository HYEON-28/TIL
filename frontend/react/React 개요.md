# React 개요

리액트: 2013년에 페이스북에서 발표한 JS 라이브러리. SPA를 만든다.
가상 DOM과 JSX라는 새로운 방식으로 동작함.

## SPA vs MPA

리액트는 `index.html` 파일 1개로 동작함. 사용자가 새로 요청한 부분만 동적으로 생성.
→ **싱글 페이지 애플리케이션(SPA)**

vs

**멀티 페이지 애플리케이션(MPA)**: 주소창(URL) 요청 방식, 새로고침이 발생할 수밖에 없음.

## 클라이언트 템플릿 엔진

- 서버쪽: DB에서 데이터를 받아와 HTML을 출력
- 클라이언트쪽: 백엔드에서 JSON 데이터를 받아와 DOM 객체로 변환
