# useContext란?
- 컴포넌트 간에 데이터를 공유할 때 사용합니다.                                               

  원래 React에서 데이터를 전달하려면 props로 부모 → 자식으로 내려줘야 합니다. 그런데
  컴포넌트가 깊어질수록 중간 컴포넌트들이 쓰지도 않는 props를 계속 받아서 아래로 전달해야 하는
   문제가 생깁니다. 이를 props drilling이라고 합니다.

  App (cart 보유)
   └─ Navbar
       └─ ProductList (cart 필요) ← props로 3단계 내려줘야 함

  useContext를 쓰면 중간 단계 없이 어느 컴포넌트에서든 바로 꺼내쓸 수 있습니다.

주로 테마, 로그인 사용자 정보, 언어 설정, 전역 상태 등을 여러 컴포넌트에서 사용할 때 사용합니다.

## useContext의 핵심 개념
1️⃣ Context 생성
2️⃣ Provider로 데이터 공급
3️⃣ useContext로 데이터 사용
