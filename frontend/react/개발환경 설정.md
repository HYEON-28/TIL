# 개발환경 설정

## VSCode 확장 프로그램

- **Prettier**: 코드 포맷터
- **Tailwind CSS**: CSS를 쉽게 작성할 수 있게 해줌
- **Headwind**: Tailwind CSS 관련 코드를 이해하기 쉬운 순서로 재배치
- **PostCSS**: 테일윈드 CSS 문법을 써도 VSCode 상 경고가 안 뜨도록

## 프리티어 무시 주석

```ts
// prettier-ignore
```

- 프리티어를 무시하며 타입스크립트 컴파일러의 타입체크 기능도 무시함
- 개발이 끝난 코드에만 무시 주석을 써야 함

## npm vs npx

- **npm**(node package manager): Node.js 프로젝트에서 오픈소스 라이브러리를 쉽게 설치할 수 있게 해줌
- CRA처럼 글로벌(`npm i -g`)로 설치해야 하는 프로그램은 최신 버전을 유지하기 힘들다는 문제가 있음
- **npx**: 패키지의 가장 최신 버전을 찾아 자동으로 글로벌 설치해 실행해 줌

## TypeScript 프로젝트 생성

```bash
npx create-react-app 프로젝트_이름 --template typescript
```

## 웹팩

다양한 프론트엔드 파일을 단순한 형태로 변환해 주는 번들러.

- `npm start`: 웹팩이 개발 서버로 동작
- `npm run build`: 빌드 모드
- `npm install -g serve` 후 `serve -s build`: 빌드된 결과물을 서빙

## 가짜 데이터 패키지

- Node.js 패키지 중 JS로 개발된 것을 TS에서 쓰려면 `@types/`로 시작하는 타입 라이브러리를 추가 설치해야 함
- **chance**: 가짜 데이터 제공
- **luxon**: `'2021/10/6'` 같은 날짜를 `'20분 전'` 형태로 만들어 줌
