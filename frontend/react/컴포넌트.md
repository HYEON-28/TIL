# 컴포넌트

## 종류

1. 클래스 컴포넌트
2. 함수 컴포넌트 → **권장**

- 리액트 컴포넌트: 리액트 기본 제공. 첫 글자 소문자
- 사용자 컴포넌트: 직접 구현. 첫 글자 대문자의 카멜 표기법

```tsx
const h1 = <h1>Hello world!</h1>;
// h1은 HTML 태그가 아닌 h1 컴포넌트임
```

## 클래스 컴포넌트

`Component` 클래스를 상속해야 하고 `render()` 메서드를 구현해야 한다.

```tsx
import { Component } from "react";

export default class App extends Component {
  render() {
    return <h1>class component</h1>;
  }
}
```

## 함수 컴포넌트

```tsx
export default function App() {
  return <h1>function component</h1>;
}
```

함수 컴포넌트는 `import`, `extends`, `render` 등의 상용구가 없어서 간결하다.

## 컴포넌트 속성(props)

- 부모 컴포넌트가 자식 컴포넌트에 정보를 전달하는 목적으로 사용
- 속성값이 변하면 해당 컴포넌트를 다시 렌더링하여 수정된 속성값을 반영해 줌

```tsx
<Person name='Jack' age={22} />
// string이 아닌 경우 {}로 감싸야 함

<Person person={{ name: 'Jack', age: 32 }} />
// object도 string이 아니므로 {}로 감쌌음
```

## key, children, ref

모든 리액트 컴포넌트는 `key`, `children`, `ref` 속성을 이미 가진다.

- **key**: 같은 이름의 컴포넌트가 여러 개일 때 이들을 구분하기 위한 속성
- **children**: 자식 속성

### `{...props}` 구문

`props`에 담긴 다양한 속성을 타입스크립트의 전개 연산자처럼 한꺼번에 전달한다.

```tsx
<p {...props} />
```

### PropsWithChildren 타입

`Props` 타입에 반복해서 `children` 속성을 추가할 필요가 없게 해 준다.

## 이벤트 속성

- `onMouseEnter`, `onMouseOver` 등 `on`으로 시작하는 속성
- 훅: `use`로 시작하는 함수
