# AOP란 무엇인가?

`Spring AOP 기반으로 트랜잭션을 처리한다`라는 문장을 보고  
AOP가 무엇인지 궁금해져 정리해보았다.


## AOP란?

**AOP (Aspect-Oriented Programming)** 는  
**관점(측면) 지향 프로그래밍**이라고 불린다.

기존의 **OOP(Object-Oriented Programming)** 가  
기능(객체) 단위로 코드를 **세로로 분리**한다면,

AOP는  
**트랜잭션, 로깅, 보안**과 같이  
여러 기능에 공통적으로 적용되는 관심사를  
**가로(관점) 방향으로 분리**한다.

즉, AOP는  
> 공통 관심사를 실행 흐름의 관점에서 분리하기 위한  
> 프로그래밍 패러다임이다.


## Spring AOP에서 처리하는 대표적인 기능들

Spring AOP는 트랜잭션뿐 아니라  
다양한 공통 기능을 처리하는 데 사용된다.

- 트랜잭션 관리
- 로깅
- 보안 / 권한 체크
- 예외 공통 처리
- 성능 측정 (메서드 실행 시간 등)

이러한 기능들은  
비즈니스 로직과 직접적인 관련은 없지만  
여러 곳에서 반복적으로 필요하다는 공통점이 있다.

  
## Spring AOP의 동작 방식 (프록시 기반)

Spring AOP는  
**실제 객체 앞에 프록시 객체를 생성**하여 동작한다.

메서드가 호출되면  
프록시 객체가 먼저 호출을 가로채고,  
메서드 실행 전·후에 공통 로직을 자동으로 실행한다.


## 마지막으로, AOP는 Spring에서만 사용하는 용어가 아니다!
AOP는 특정 프레임워크의 기능이 아니라
프로그래밍 패러다임이다.

따라서 Spring에서 AOP라는 용어를 직접 사용하지 않더라도,
비슷한 개념은 여러 언어와 프레임워크에서 찾아볼 수 있다.

Python
- Middleware: 요청 전/후 처리
- Decorator: 함수 실행 전/후 로직 감싸기

JavaScript / Node.js
- Middleware
- Interceptor

---

## 정리
- AOP는 공통 관심사를 분리하기 위한 프로그래밍 패러다임이다.
- Spring AOP는 프록시 기반으로 메서드 실행 전·후에 공통 로직을 적용한다.
- 트랜잭션, 로깅, 보안 등 다양한 기능이 AOP로 구현된다.
- AOP 개념은 Spring뿐 아니라 여러 언어와 프레임워크에서 활용된다.
