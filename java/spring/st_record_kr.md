# record vs @Data(Lombok)
DTO용도로 객체를 만들 때 위 두가지 방식이 있다. 
기존 회사코드에서는 @Data(Lombok)을 사용하였기 때문에 새로운 방식인 record와 비교하여 어떤점이 다른지 알아보았다.

## record?
- record는 Java 16에서 정식으로 추가된 문법.
- 생성자, getter, equals, hashCode 등을 직접 만들필요가 없이 내부에 구현이 되어있다.
- **데이터의 변경이 없는 경우** 사용하며 불변성이 강제된다
- 데이터 전송용이라는 의도가 명확히 표현된다


## @Data
- 외부 라이브러리가 필요하다
- 기본은 가변적인 특성을 가진다
