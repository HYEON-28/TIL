# 타입

## double과 Double의 차이
| 구분   | double          | Double                             |
| ---- | --------------- | ---------------------------------- |
| 타입   | primitive (기본형) | 객체 (Wrapper Class)                 |
| null | ❌ 불가능           | ✅ 가능                               |
| 성능   | 빠름 (메모리/연산 효율적) | 느림 (객체 생성/GC 영향)                   |
| 컬렉션  | ❌ 사용 불가         | ✅ 사용 가능 (`List<Double>`)           |
| 메서드  | ❌ 없음            | ✅ 있음 (`parseDouble`, `toString` 등) |

기본적으로는 `double`을 쓰고, `null`이 필요하거나 컬렉션에 담아야 할 때만 `Double`을 쓰면 된다.

## 오토박싱 / 언박싱

Java가 `double` ↔ `Double`을 자동으로 변환해줌.

```java
Double d = 3.14;      // 오토박싱: double → Double
double d2 = d;        // 언박싱: Double → double
```

편리하지만 `Double`이 `null`인 상태에서 언박싱하면 `NullPointerException`이 발생하니 주의.
