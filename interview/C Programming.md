1. C 언어 (C Programming)
   임베디드 소프트웨어의 핵심 언어로, 메모리에 직접 접근하고 제어하는 능력을 검증합니다.

포인터와 메모리 주소: 포인터(Pointer)와 배열(Array)의 차이점은 무엇인가요? 포인터 배열과 배열 포인터의 차이를 설명해 주세요.

키워드 활용: static, volatile, const 키워드의 역할과 임베디드 환경에서 왜 중요한지 각각 설명해 주세요. (특히 volatile이 인터럽트 처리나 하드웨어 레지스터 접근 시 왜 필수적인지?)

메모리 구조: C 언어 프로그램이 실행될 때 메모리 영역(Code, Data, BSS, Heap, Stack)이 어떻게 나뉘는지 설명하고, 지역 변수와 전역 변수가 각각 어디에 저장되는지 설명해 주세요.

메모리 동적 할당: malloc과 free를 사용할 때 발생할 수 있는 문제점(예: 메모리 단편화, Memory Leak)은 무엇이며, 임베디드 시스템에서 동적 할당을 지양하는 이유는 무엇인가요?

비트 연산: 특정 비트를 설정(Set), 클리어(Clear), 토글(Toggle)하는 비트 연산자(AND, OR, XOR, NOT, Shift)의 사용법을 설명해 주세요.
